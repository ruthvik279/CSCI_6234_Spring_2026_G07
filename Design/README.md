# Design

This folder contains the design artifacts for the Code Review Automation Assistant project.

## Contents

### SequenceDiagram/
Contains sequence diagrams for each of the 6 use cases:
- **SubmitPullRequest** - UC1: Developer submits a pull request and receives automated review feedback
- **ViewReviewComments** - UC2: Developer views automated review comments on their pull request
- **ViewDashboard** - UC3: User views the code quality dashboard with metrics and trends
- **ConnectRepository** - UC4: Admin connects the system to a GitHub repository
- **ConfigureRules** - UC5: Admin configures code review rules and quality gates
- **GenerateReport** - UC6: Admin generates a code quality report for a repository

### ClassDiagram/
Contains the complete class diagram with all entity classes, attributes, methods, and associations.
